## 新增：桌面 GUI（`src/MediaCli.Transcode.Gui`，mediac-gui）

- **框架**：WinForms / `net8.0-windows`，零额外 NuGet 依赖。
- **功能**：输入（文件/目录，可多行）、preset 下拉、hwaccel 与解码模式选择、输出目录与模式、
  自定义参数输入框、覆盖/严格/详细日志/动漫开关、日志面板（着色 + 自动滚动 + 行数上限）、
  进度条、预览命令 / 开始转码 / 取消 / 清空日志 / 打开输出目录。
- **分层**：`GuiOptions`（UI→core 纯映射）、`FfargsValidator`（ffargs 校验）、
  `TranscodeSession`（串行编排 + 取消，等价于 core 未实现的 Engine 层）、`LogSink`（无锁队列 + 批量刷新）。
  前两者不含 WinForms 类型，可被 xUnit 直接覆盖。
- **可靠性要点**：
  - 预览与真实执行**同路径**（走 `TestMode`），先完成真实硬件分层决策再提前返回，
    故预览命令与执行命令一致；识别 core 的 `"test-mode skip"` 哨兵，避免预览被误报为失败。
  - 日志走 `ConcurrentQueue` + 100ms 定时批量刷新，避免高频 `Invoke` 拖慢转码。
  - 执行整体置于后台线程（core 为同步模型，内部 `WaitForExit`）。
  - 严格串行（core 为同步模型 + 进程内静态缓存，并发会互相污染）。
  - 关窗保护：任务运行中先取消并等待进程退出，避免 ffmpeg 变孤儿进程。
  - 启动诊断：显示实际使用的 ffmpeg/ffprobe 路径、版本、GPU、可用硬件层。

## 变更：目标框架 net10.0 → net8.0

- `Directory.Build.props`：`TargetFramework` 改为 `net8.0`，新增 `RollForward=Major`
  （缺失 8.x 运行时则前滚到最低更高主版本 10/12；不选 `LatestMajor` 以避免无条件挑最高版本）。
- GUI 项目显式覆盖为 `net8.0-windows`；测试项目同步为 `net8.0-windows`。

## 变更：预设文件归位

- `src/MediaCli.Transcode/Assets/default.yaml` → 仓库根 `presets/default.yaml`
  （与 README 结构、上游 media-cli.js 约定、csproj 引用意图一致；内容哈希核对一致）。
- **修复既有缺陷**：csproj 原引用 `..\..\..\presets\default.yaml` 解析到不存在的
  `C:\Home\Projects\presets\`，导致 `dotnet build` 报 `MSB3030` 失败。改为 `..\..\presets\`。

## 变更：行尾与格式约定

- 新增 `.gitattributes`：仓库内统一 LF（`*.cs text eol=lf diff=csharp`），
  `*.bat`/`*.cmd` 保持 CRLF，二进制禁转换。
- 新增 `.editorconfig`：`end_of_line = lf`、`charset = utf-8`、C# 4 空格、XML 类 2 空格。
- 归一 15 个文件的行尾（此前仓库混用：21 LF / 10 CRLF）。
  **效果**：`FFmpegPresets.cs` 的 diff 从虚假的 735 行恢复为真实的 7 行。
- 刻意不在 `.editorconfig` 声明分析器严重级别（`TreatWarningsAsErrors=true` 下会致构建失败）。

## 修复：既有警告（`TreatWarningsAsErrors=true` 后暴露为错误）

  与同文件 `ToEven_Exact` 的 `608/570` 矛盾）且参数未被使用。经 node 跑 JS 原版核实为
  `608/570`，按实测修正并让断言真正使用参数。
- `PlanAndBuildTests`：`entry.Info.Video` 可空解引用 → 加 `Assert.NotNull`。
- `Cli/Program.cs`：`Next()` 局部函数返回类型 `string?` → `string`（其实现永不返回 null）。

## 变更：进程 stderr 编码显式固定

- `FfmpegRun`：新增 `StandardErrorEncoding = Encoding.UTF8`。
  实测 .NET 8 默认解码已是 UTF-8（中文路径可正常显示），**非缺陷修复**；
  显式固定是为了不依赖宿主控制台状态（GUI 由资源管理器启动与终端启动码页可能不同）。

## 核心逻辑改动说明

- `FFmpegPresets`：新增只读属性 `ArgAliasesView`（别名表视图，供上层做键合法性预检，

- `FfmpegRun`：仅新增 stderr 编码设置，**不触及命令构建、分层决策、滤镜与编码器参数**。
