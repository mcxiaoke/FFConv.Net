# 变更记录 2026-09-30 (对齐 ffconv-electron 核心转码缺陷修复)

> 时间：2026-09-30 14:25 (GMT+8)
> 范围：`src/MediaCli.Transcode`（核心类库全部子目录）、`tests/MediaCli.Transcode.Tests`
> 类型：核心转码逻辑缺陷修复与功能对齐

## 背景

对比 `C:\Home\Projects\ffconv-electron` 生产环境积累的修复记录与当前 C# 项目 `c:\Home\Projects\FFConvNet`（`MediaCli.Transcode`），发现并对齐了 14 项核心非 GUI 转码逻辑缺陷，涉及媒体探测、流映射、硬件加速推导、预设继承合并与运行状态保护。完整分析见 `docs/TRANSCODE-CORE-PARITY-FIXES-20260930.md`。

## 重点变更摘要

1. **媒体探测与流序号 (`MediaInfo` / `FfprobeMediaInfo`)**：
   - `VideoInfo` 增加 `StreamIndex` 字段。
   - 增加封面判定与过滤（三档分类：`NotCover`、`SuspectedCover`、`ConfirmedCover`），防止音频文件或多流视频中附带的静态专辑封面被误选为主视频流进行转码。
   - 解析 ffprobe 视频流的绝对流序号 `StreamIndex`。
   - 支持 SAR（像素宽高比）显示尺寸校正（按 DAR 修正有效宽度）及帧率字符串（`num/den`）精确解析。

2. **流映射与转码编排 (`FfmpegBuild` / `FfmpegPlan`)**：
   - 引入 `VideoStreamMapArgs` 与 `PushStreamMaps`：检测到有效流序号时以绝对序号 `-map 0:<idx>` 映射视频流；序号缺失时整组不输出 `-map` 并由 ffmpeg 默认流选择兜底。
   - 1:1 分辨率下消除多余 `scale=` 重采样滤镜（当源尺寸等于目标尺寸且无前后滤镜与变速时，跳过无谓的缩放滤镜）。
   - 字幕参数守卫改为 `tempPreset.Type != "video"`，彻底解决 `audio_extract` 预设从视频提取音频时注入额外 `-map 0:a?` 导致生成重复双音轨的缺陷。
   - WebM 容器字幕强制 `-sn` 丢弃（WebM 容器不支持 mov_text / copy 字幕，避免 ffmpeg muxer 直接报错）。
   - 音频流复制前校验容器兼容性（如 MP4 不兼容 Vorbis/Cook 等），不兼容时自动安全回退为 `aac` 重编码。

3. **硬件加速与候选链推导 (`HwAccel` / `HwDetect`)**：
   - 显存帧软件滤镜域仅在目标输出必须为 8-bit 时转换 `nv12`，其余情况保留 `p010le`，避免 10-bit HDR/SDR 高位深内容发生截断。
   - `ProbeCacheKey` 缓存键纳入 `quality` 参数，避免相同预设不同质量共用相同探测缓存。
   - `CandidateTiers` 对 `--hwaccel cpu` 明确只返回 `["cpu"]`，不再下穿执行 GPU 探测链。
   - 设备探测增加 8000ms 超时限制，防止驱动异常挂起。

4. **预设加载与参数覆盖 (`PresetLoader` / `FFmpegPresets`)**：
   - `ResolveExtends` 修复跨层与多层继承，引入 `basePresets` 备查字典，支持用户预设正确继承内置预设。
   - `ValidatePresetFields` 真正从预设字段中移除未知或类型不匹配字段，并记录警告。
   - `ParseFfargs` / `ApplyFfargs` 支持带单位字符串码率（如 `vb=2500k`、`ab=192k`）、裸布尔标志（如 `anime`）。
   - `CreateFromArgv` 找不到预设时输出当前全部可用预设名称；当使用 `--video-copy` 时，统一清理 `Dimension=0, Framerate=0, Speed=1.0`。

5. **任务执行与取消容错 (`FfmpegRun`)**：
   - 在任务被取消时，若产物文件已被成功完整写入磁盘且大小有效，优先保留 `Ok = true`，避免将已完成的任务误报为取消失败。
